# Contribuindo

1. Crie uma branch para a alteração.
2. Mantenha a API pública documentada.
3. Adicione testes para regras fiscais novas ou corrigidas.
4. Execute `dart format lib test`, `dart analyze` e `dart test`.
5. Documente a fonte oficial, schema ou versão do NFePHP usada.

Não declare uma funcionalidade fiscal como completa apenas porque o XML foi gerado: inclua evidência de validação estrutural e, quando aplicável, testes de autorização em ambiente de homologação.
