# Matriz de compatibilidade com NFePHP

A matriz é incremental. Itens não listados ainda não foram portados e não devem ser tratados como implementados.

## Inventário reproduzível de assinaturas

Além da matriz funcional abaixo, `tool/verify_nfephp_signatures.dart` extrai os
parâmetros reais dos métodos públicos da referência fixada e registra, para
cada método `Make` e `Tools`, a declaração Dart encontrada. A verificação é
executada na CI contra o commit NFePHP fixado e falha quando um método da
referência não possui fachada Dart. Como os parâmetros PHP frequentemente são
`stdClass`, estado implícito ou valores opcionais, a declaração Dart pode usar
modelos tipados e uma assinatura diferente; essa divergência fica visível no
relatório gerado, em vez de ser tratada como igualdade textual.

Comando reproduzível:

```sh
dart run tool/verify_nfephp_signatures.dart \
  --php-make /caminho/sped-nfe/src/Make.php \
  --dart-make lib/src/make.dart \
  --php-tools /caminho/sped-nfe/src/Tools.php \
  --dart-tools lib/src/tools.dart \
  --report /tmp/flutter-fiscal-api-signatures.md
```
